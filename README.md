# Atelier de Carteras — prototipo visual

Primera maqueta web para explorar la selección de modelos, personalización visual de carteras y una vista ilustrativa de moldes.

## Estado

Solo prototipo visual. Los gráficos de cartera son SVG conceptuales: **no son renders 3D ni patrones de fabricación validados**. La vista de moldes no está a escala ni lista para impresión real.

## Uso

Abrir `index.html` en un navegador o publicar la raíz de la rama `main` con GitHub Pages.

La selección de color, las medidas de ejemplo y un borrador local sirven para explorar la experiencia. Más adelante, los moldes vectoriales provistos por el equipo y las fotos/renderizados sustituirán los recursos de prueba.
